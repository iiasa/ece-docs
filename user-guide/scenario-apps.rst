Using Scenario Apps
===================

The following steps guide users on the features available in the 
:ref:`current generation <scenario-databases>` of Scenario Apps.

.. toctree::
   :maxdepth: 1

   scenario-apps/scenario-submission
   scenario-apps/data-explorer
   scenario-apps/map-explorer

In these pages, you will learn how to:
- use the Scenario Submission page to upload IAMC data
- use the Data Explorer page to visualise IAMC data graphs and tables, and create
  workspaces
- use the Map Explorer to visualise IAMC data geographically
