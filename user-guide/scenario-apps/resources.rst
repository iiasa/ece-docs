.. _resources:

Resources pages
===============

The Resources pages include a variety of key information for a particular 
model-comparison project.
Typically, there are at least five pages included in a project:

Documentation
-------------

The **Documentation** page includes a short description of the project, and can
include information like citations to relevant publications, such as papers
describing the models present in the study, or papers resulting from the project,
links to repositories, such as code repositories like GitHub, or data repositories,
like Zenodo.

Definitions
-----------

The **Definitions** page includes an automatic compilation of all the allowed values
(definitions) configured for the project for which there is data.
The definitions are divided in their dimensions: models, scenarios, regions, variables.
Each entry optionally includes a description that provides additional information.

Data Access API
---------------

The **Data Access API** page showcases a simple example on how to programatically
access the data stored in the project's scenario database, using either the Python
or R programming languages.

License
-------

The **License** page clarifies the intellectual property rights that are applicable
to the Scenario App. Namely, the copyright of the Web App itself falls on IIASA
and the institutions that may collaborate with it in for each project.

The copyright and licenses governing the data presented in Scenario Apps may vary
from case to case, and so it is important to consult this page to ensure proper
usage rights are ensured if data is reused or accessed.

About
-----

The **About** page provides additional context about the project, such as the
background to its establishment, information on the partner organizations, and
any other relevant details.
