Preparing Scenario Submissions
==============================

The following steps guide users from registering new Scenario Explorer accounts
to preparing scenario data in the IAMC format and uploading a data file.

.. toctree::
   :maxdepth: 1

   preparing-scenario-submissions/user-account
   preparing-scenario-submissions/model-registration
   preparing-scenario-submissions/data-format
   preparing-scenario-submissions/scenario-submission

In these pages, you will learn how to:

- register an account in the Scenario Services Manager
- setup access and submit (upload) permissions for a Scenario Explorer app
- register a model for a project in order to submit of scenarios
- format and preprocess data for submission (upload) in a Scenario Explorer app
- submit a scenario (i.e., upload a file with scenario data)

.. tip::

   To learn about Scenario Apps' features for data visualization and analysis, go to
   :ref:`scenario-apps`.
