*nomenclature* scenario management
==================================

**nomenclature** is an in-house developed Python package that is used in multiple
steps of the Scenario Submission process:

1. Management of the standard language used to define codelists ("definitions")
2. Processing of configuration files for model-comparison projects
3. Scenario workflow scripts for data processing during upload
   
   - Region aggregation during workflow processing

To learn more about each of these, please see the guides below:
